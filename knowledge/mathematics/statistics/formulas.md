# Statistics Formulas

Mean = sum of observations / number of observations.

Median = middle value after arranging data in order.

Mode = value that appears most frequently.

Range = maximum value - minimum value.

Variance for population = sum((x - mean)^2) / N.

Standard deviation = square root of variance.

Probability of event = favorable outcomes / total outcomes.

Complement probability: P(not A) = 1 - P(A).

For independent events: P(A and B) = P(A) x P(B).

For mutually exclusive events: P(A or B) = P(A) + P(B).
