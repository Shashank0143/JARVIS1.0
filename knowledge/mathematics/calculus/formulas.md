# Calculus Formulas

## Differentiation

d/dx c = 0

d/dx x^n = n x^(n-1)

d/dx sin x = cos x

d/dx cos x = -sin x

d/dx tan x = sec^2 x

d/dx e^x = e^x

d/dx ln x = 1/x

Product rule: d(uv)/dx = u dv/dx + v du/dx

Quotient rule: d(u/v)/dx = (v du/dx - u dv/dx) / v^2

Chain rule: d f(g(x))/dx = f'(g(x)) g'(x)

## Integration

Integral of x^n dx = x^(n+1)/(n+1) + C, where n is not -1.

Integral of 1/x dx = ln absolute x + C.

Integral of e^x dx = e^x + C.

Integral of sin x dx = -cos x + C.

Integral of cos x dx = sin x + C.

Integral of sec^2 x dx = tan x + C.
